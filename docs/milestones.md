# Implementation Milestones

## Milestone 1: Core Database

- Supabase Auth and membership roles.
- People, organisations, roles, tags, and search.
- Motion Scout and LinkedIn export import staging.
- Audit log, soft delete, suppression list, and privacy status.

## Milestone 2: Relationship Intelligence

- Relationship entities with source evidence and confidence.
- LinkedIn message and recommendation import.
- Warmth calculation separate from strategic value.
- Network graph and shortest introduction paths.

## Milestone 3: Public Enrichment

- Manual URL evidence intake.
- Compliant web/search provider adapter.
- Social account linking with human review.
- Entity resolution and duplicate review queue.

## Milestone 4: Discovery

- Watch topics.
- Daily incremental news and web scans.
- New people and organisations enter Review Required.
- Change detection for jobs, campaigns, roles, funding, media, and policy.

## Milestone 5: AI Intelligence

- Structured JSON agents for discovery, extraction, resolution, classification, evidence, red-team, relationship, opportunity, outreach, and digest.
- Fit scores with explanation, evidence, and uncertainty.
- Red-team tests for tokenism, sensitive inference, and fame bias.

## Milestone 6: Outreach Intelligence

- Respectful approach strategy.
- Warm route selection.
- Mutual-value prompts.
- Human approval workflow.
- No automated sends.

## Milestone 7: Advanced Community OS

- Daily briefing archive.
- International discovery.
- Funding and policy tracking.
- Events, campaigns, and second-degree routes.
- Semantic search and graph exploration at scale.

## Immediate Versus External-Access Work

Immediate:

- Local Next.js app.
- Supabase schema.
- Manual evidence records.
- Import staging interfaces and docs.
- Search/ranking/relationship logic over stored data.

Requires external access:

- LinkedIn exports from Ben.
- Motion Scout exports.
- Meta app approval.
- TikTok approved API or compliant provider.
- YouTube Data API key.
- Licensed or compliant news/search provider.
- Production Supabase project credentials.
